# Fotografias do site

As imagens ficam em `public/images`, uma pasta por seção. O mapeamento de cada arquivo está em
`src/content/images.ts`: para trocar uma foto, troque o arquivo na pasta e ajuste o caminho nesse arquivo.

| Pasta | Uso no site | Arquivos |
| --- | --- | --- |
| `logo/` | Logotipo oficial (cabeçalho e rodapé) | `comilancia-logo.webp` (fundo transparente) |
| `hero/` | Fotografia de abertura | `cozido-carne-legumes.webp` |
| `historia/` | Seção "Nossa História" | `cozinha-ovos-torta.webp` |
| `buffet/` | Gastronomia (buffet) e galeria | `batata-palha-camarao.webp`, `batatas-recheadas-camarao.webp`, `entradas-mezze.webp` |
| `japonesa/` | Gastronomia (japonesa) e galeria | `sushi-prato-da-casa.webp`, `sushi-sake.webp` |
| `sobremesas/` | Gastronomia (sobremesas) | `torta-maca-canela.webp` |
| `ambiente/` | Galeria: salão e ambiente | **vazia**: falta fotografia oficial |
| `galeria/` | Galeria | `saladas-antepasto.webp`, `couve-linguica-carne.webp`, `carne-queijo-tomate.webp`, `torradas-tomate.webp`, `ovos-quiche-linguica.webp`, `sobremesa-morango.webp`, `nhoque-ragu-manjericao.webp` |
| `public/images/` | Imagem de compartilhamento (Open Graph e dados estruturados) | `og-cover.jpg`: recorte de 1200 × 630 da fotografia de abertura |

## Pendências

- Fotografia do salão, da fachada ou do ambiente (história e categoria "Ambiente" da galeria).
- Os arquivos vieram do site oficial e das fotos enviadas pelo restaurante. Confirme com o responsável que o uso está autorizado.

## Regras

- Use somente fotografias do Restaurante Comilância.
- Cada foto deve aparecer uma única vez no site.
- Formato: WebP, com até 1600 px de largura. Para trocar o logotipo, use um arquivo PNG ou SVG com fundo transparente.
- Fotos de terceiros, banco de imagens e conteúdo do Instagram só com autorização do restaurante.
